# Real Flow Smoke Test

A real smoke remains a separate operational activity for a disposable repository when Astra, Herdr and AGY are available. It is not part of ordinary static skill maintenance.

The minimum real flow is: Astra Contract → Herdr/AGY implementation → Astra code review → frozen command plan → AGY command execution/result recording → deterministic completion gate.

If the environment is unavailable, report `FLOW_VERIFIED=NOT_RUN` or BLOCKED. Do not substitute static inspection or mock evidence for a real flow.
