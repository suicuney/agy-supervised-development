# Legacy 3.x workflow

This directory marks concepts removed from the active 4.0 execution path: default Sol/browser plan review, Shape/Spec/Slice, Execution Units as a planning layer, mandatory Three-Axis Review, and closeout ceremony.

They are **not** loaded by the 4.0 router and must not be used as default behavior.

The complete historical 3.x documents remain available in Git history before `4.0.0-alpha.4`. Keep this directory intentionally small so progressive disclosure cannot accidentally reactivate the old workflow.

Sol High/browser review is legacy/optional only when the user explicitly asks for that historical capability; it is never a prerequisite for Contract freeze, AGY execution, review, or acceptance.
